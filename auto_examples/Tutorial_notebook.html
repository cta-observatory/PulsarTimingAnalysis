Basic pulsar analysis using Fermi-LAT data#

This example shows how to produce the phaseogram of the Crab pulsar, compute the statistics of its peaks, search for pulsations, fit the pulse profile and study the evolution of the signal with time and energy.

It uses about 10 years of public Fermi-LAT observations of the Crab pulsar (100 MeV - 1 GeV), for which the pulsar phases were already computed.

Create the PulsarAnalysis object and settings#

All the settings of the analysis can be read from a configuration file:

35 h = PulsarAnalysis()
36 h.set_config("./example_data/config_tutorial.yaml")

Alternatively we can set the parameters directly#

The phase regions used to compute the statistics of the peaks (P1 and P2) and to estimate the background, the binning of the phaseogram, the time interval used to follow the evolution of the signal, the model used to fit the pulse profile and the energy binning:

47 h = PulsarAnalysis()
48 h.setBackgroundLimits([0.52, 0.87])
49 h.setPeaklimits(
50     P1_limits=[0, 0.026, 0.983, 1], P2_limits=[0.377, 0.422], P3_limits=None
51 )
52 h.setBinning(50, xmin=0, xmax=1)
53 h.setTimeInterval(tint=3600 * 24)
54 h.setFittingParams(model="dgaussian", binned=True)
55 h.setEnergybinning(
56     np.geomspace(0.1 / 1e3, 1 / 1e3, 3), do_diff=True, do_integral=False
57 )  # in TeV

Extracting phases, times and energies from file and give them to the object#

For Fermi data there is a class to read these lists and use them in the main object.

66 h.setFermiInputFile("./example_data/merged2_pulsar.fits")

But in general we can read our file (FITS, DL2, DL3…) and extract phases, times and energies as lists and read them as follows:

73 with fits.open("./example_data/merged2_pulsar.fits") as f:
74     fits_table = f[1].data
75     times = np.array(fits_table["BARYCENTRIC_TIME"], dtype=float)
76     phases = np.array(fits_table["PULSE_PHASE"], dtype=float)
77     energies = np.array(fits_table["ENERGY"], dtype=float)  # in MeV
78
79 h.setListsInput(phases, times, energies / 1e6, tel="fermi", energy_units="TeV")
